✨ New: Browser-Based AI!
The extension now uses AI models running directly in your browser.
No Python backend required! Just install and use.
Browser-Based Mode:
• No installation required
• Faster on modern GPUs
• Complete privacy (all processing in browser)
• Works offline after first model download

Backend Mode:
• Requires Python backend running on localhost
• Uses Ollama with moondream:1.8b model
• Only use if you prefer the old setup
Quick Mode:
• Automatically detects code blocks and extracts text directly
• Much faster than image processing
• Uses lightweight text LLM for explanations
• Fallback to image mode for non-code content
Note: Make sure your backend server is running at the specified URL.
